# E0001: unexpected character

Outside comments, a wrela source file holds only ASCII: identifiers (letters, digits and `_`, not
starting with a digit), numbers, operators and punctuation, spaces, tabs and line breaks. Any other
character is an error. Comments may contain any text.

Common causes are a letter outside ASCII in a name (`π`, `é`), typographic quotes or dashes pasted
from a document, and invisible characters such as a zero-width or non-breaking space. Invisible
characters are reported by their code point, like `U+00A0`.

```wrela bad
fn area(r: f32) -> f32 {
    let π = 3.14159
    π * r * r
}
```

Spell the name in ASCII:

```wrela fixed
fn area(r: f32) -> f32 {
    let pi = 3.14159
    pi * r * r
}
```
