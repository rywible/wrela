# E0002: `/* */` comments aren't supported

A comment starts with `//` and runs to the end of the line; `///` starts a doc comment. wrela has no
block comments, so `/* ... */` is an error. The compiler skips to the matching `*/` (block comments
nest, as in Rust) and keeps checking, so one stray comment doesn't hide later problems.

```wrela bad
/* The area of a circle of radius `r`. */
fn area(r: f32) -> f32 {
    3.14159 * r * r
}
```

Write each line as a `//` comment:

```wrela fixed
// The area of a circle of radius `r`.
fn area(r: f32) -> f32 {
    3.14159 * r * r
}
```
