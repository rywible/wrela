# Wrela Global DB Governance Docs

This directory captures execution-surface governance artifacts for the
`Wrela Global DB (Spanner-Style, HLC) Big Bang` project.

## Scope

- Canonical dependency ordering for phase-overlay work.
- Policy/ABI policy guardrails for issue authorship.
- Lightweight checks that can be wired into future CI scripts.
- Gate registry and evaluator inputs for G2 automation.

All changes here are intended to make G1/G2 issues verifiable without waiting
on runtime implementation work.
