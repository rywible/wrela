Compile stable light transport; spend runtime work on change

These are proposed experiments, not implemented improvements or promised speedups. Our source semantics can describe shape, material, openness, repeated structure and change dependencies before a pixel is shaded.

Surface-aware visibility

Compile valid probe neighborhoods and conservative clear/blocked relationships for receiving patches. Refine around contacts, walls and openings. Stop rediscovering the same static blockers up to eight times per shaded pixel.

Visual gate: closed rooms stay dark; no probe-boundary bands.

Static multi-bounce relighting

Extend the existing sky-transfer basis to fixed geometry and reflectance with more diffuse bounces. Separate broad sky from sharp sun/aperture information. Track affected transport when doors or materials change.

Visual gate: snow and pale stone bounce without uncontrolled leaks.

Local reflected surroundings

Compile scene reflection/visibility products for rooms, rock groups and canopy. Use cheap radiance for rough surfaces; reserve richer queries for smooth hero materials. Diffuse and glossy light share a world, not identical bandwidth.

Visual gate: the sealed-room metal test passes.

Near/far cached shadows

Separate static casters from characters and wind-driven foliage; reuse valid static depth. Choose shadow detail from the light and receiver footprint, including off-camera casters.

Visual gate: feet and thin objects stay grounded during traversal.

Smaller, correctly filtered material programs

Specialize only proven feature combinations. Preserve slope, coverage and correlated lighting as details become unresolved. Align water/solid local-light rules and verify coat/roughness energy.

Visual gate: no unstable sparkle, changing material identity or mismatched light range.

One integrated acceptance valley

Walk from open ground through canopy into a room, past metal, wet stone, creature, brook and lantern. Test daylight, overcast, low sun and night. Record p95 frame cost, rebuild spikes, memory and reference error.

Performance gate: existing Alpine 12 ms GPU / 4 ms CPU p95 targets, then weaker hardware.

Yes, quality and performance can improve together. Fewer repeated queries can buy more correct visibility and bounce. Beating today’s GI-off frame while adding every effect remains an experiment.
