# Sky fixes: implementation and visual review

23 September 2026. Changes for all five areas in the [current sky audit](sky-current-audit-2026-09-23.md) are implemented in the production renderer and alpine environment, with new authoring controls and verification.

The [before/after board](sky-fixes-2026-09-23/index.html) contains **36 new renders, 21 before views, and the same 12 credited references**. It includes daylight, sunset, twilight, night, storm, all compass directions, independent layers, four tower seeds, maturity variation, separated remnants, the alpine cameras, and three quality settings. The originals are unretouched. Different cameras in the isolated morphology study are explicitly labeled.

| Audit gap | Implemented change |
| --- | --- |
| Repeated cloud structures | A deterministic growth compiler generates bounded branch positions, widths, unequal crowns, secondary updrafts, and detached shoulders. Seeds change the broad shape. Towers, banks, and remnants use different arrangements. |
| Uniform solid edges | Growth activity and authored maturity control erosion and the transition into air. Young tips keep coherent billows; weaker shoulders dissolve more strongly. Wisps have smaller separated envelopes, reduced extinction, and torn margins. Background weather has stronger medium-scale billows and varying density slope. |
| Patterned high wisps and missing layers | Independent middle and high decks have coverage, altitude, orientation, and different drift speeds. High cloud uses filtered, wind-stretched turbulence and oblique noise slices instead of repeated curved ribbon envelopes. Both decks intersect spherical shells and receive atmospheric attenuation along their own distances. |
| Weak distant depth | The low-cloud integration range extends from 32 to 48 km along the supported shell. Four atmospheric distance bands replace three, separating clouds beyond 35 km from nearer masses. Upper layers no longer disappear at the old planar horizon cutoff. |
| Flat or uniform cloud lighting | Diffuse visibility now samples four broad sky directions independently of the solar shadow. The shared light cache stores this visibility. Cloud bodies receive sky light through openings and around shoulders, including at grazing sun angles. View, reflection sky, and environment lighting use the shared cloud model. |

The main implementations are [compiled growth](/Users/ryanwible/projects/wrela/packages/render-webgpu/src/cloud-formations.ts:20), [density and erosion](/Users/ryanwible/projects/wrela/packages/render-webgpu/src/atmosphere-clouds.wgsl:206), [diffuse visibility](/Users/ryanwible/projects/wrela/packages/render-webgpu/src/atmosphere-clouds.wgsl:377), and [upper layers](/Users/ryanwible/projects/wrela/packages/render-webgpu/src/atmosphere-clouds.wgsl:438). The display transform and authored exposure values were not changed to make these comparisons look better.

The [Studio controls](/Users/ryanwible/projects/wrela/apps/studio/src/environment-authoring-panel.tsx:113) expose maturity, growth lean, middle-cloud coverage/altitude/rotation, and high-cloud altitude. Existing seed and rotation controls remain. The new properties validate, serialize, undo/redo, and interpolate through weather keys. Old documents remain valid; an absent middle layer defaults to zero coverage. The middle deck stays above the bounded convective volume. The alpine weather group now includes a growing tower, a mature bank, separated remnants, and a restrained middle layer.

**Cost was addressed alongside appearance.** The weather field now provides a conservative empty-region distance derived from its noise slope. It checks weather occupancy before fetching more expensive shape/detail noise and intersects that bound with authored formation support. This lets rays skip proven empty intervals. The view budgets remain unchanged: Low 64 samples; Balanced 384 background / 512 with formations; High 1,024. No additional noise or light texture was added. Layer changes no longer rebuild the unrelated low-cloud light field. Mixed-depth history includes the middle and high layers and rejects incompatible edits or wind steps.

The layer-only cases are independent of the volume sampling count, so equality with a low-step volume run is expected. Agreement with denser rendering checks integration accuracy and reconstruction; it does not prove natural morphology or physical lighting correctness. The images were also reviewed against the original reference collection.

**The matched performance comparison uses the same surrounding renderer.** A separate baseline snapshot overlays the previous sky implementation and environment onto the final renderer; only the sky uniform section of the shared scene shader is replaced. Both runs use Balanced clouds, temporal reconstruction, the same simple terrain scene, 1024 × 768 output, the same camera/time sequences, and 60 measured frames per case. GPU timings were complete, with no dropped samples.

This measures one Apple / Metal adapter and a simple sky study. It is not a full-game benchmark or broad hardware certification. The matched run still recorded a roughly 38 ms frame-time spike, so sustained 60 fps is not established. The preliminary comparison, made before matching the surrounding renderer, is retained in the evidence rather than used for the table.

The remaining practical limits are explicit: low clouds still use a bounded procedural model and approximate scattering; the upper decks are thin layers intended for ground views, not close cloud flight; and an independently converged atmospheric/cloud light-transport reference has not been added. Some large storm masses remain smoother than the strongest AAA references. These changes expand the shape and lighting system and improve the tested composition; they do not certify complete visual parity with every reference.

The final review used a frozen source snapshot so concurrent water and surface-lighting changes could not move the target during verification. Nineteen touched files still match that snapshot byte for byte. The sky uniform section of the shared scene shader also matches; unrelated water/history/contact-lighting changes occurred elsewhere in that file. A final render checked integration in the current workspace. The alpine before/after pictures may also reflect concurrent changes to surrounding content.
