# Contributing to Wrela

Thank you for helping build Wrela. This project is governance-driven and spec-first.

Before you start:
- Read CHARTER.md and core/spec/spec.wr.
- Use the templates in .wrelahub/templates for RFCs, mandates, and analysis reports.

Contribution rules (initial):
- Spec changes require spec tests under tests/spec.
- Use Developer Certificate of Origin (DCO) sign-offs on all commits.
- One open PR per contributor (early phase).
- All changes are subject to domain-scoped review.

DCO sign-off example:

Signed-off-by: Your Name <you@example.com>

How to propose changes:
- For bugs or behavioral gaps, open an Analysis Report (template).
- For design changes, open an RFC draft.
- For implementation work, open a PR with the required structured fields.
